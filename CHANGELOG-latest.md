## EZActions 2.0.3.5.1 (fork)

This is a fork of [z2six/EZActions](https://github.com/z2six/EZActions), based on upstream release **2.0.3.5**. The mod itself is unchanged from upstream.

- Adds GitHub Release automation, so Hopper can install and update the mod from this repo's releases.
- Adds a daily upstream sync that merges new upstream versions and releases them as `<upstream version>.<fork revision>`.
- Adds the mod icon (`ezactions.png`), which the mod metadata referenced but which was missing.
- Jars are now named `ezactions-<version>+<loader>-<mc>.jar`.
